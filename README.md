Файл .gitignore в папке terraform

В данном файле используются следующие правила синтаксиса `.gitignore`:
- Символ `*` (звёздочка) означает любую последовательность символов (или её отсутствие).
- Символ `/` в конце имени указывает, что игнорируется именно директория (папка), а не файл.
- Если в правиле нет специальных символов, Git ищет файл с точным совпадением имени.

Благодаря добавленному `.gitignore`, Git будет игнорировать следующие файлы и папки, в соответсвии с правилами синтаксиса гитигнор:

- `.terraform/` — будет игнорироваться папка с точным именем `.terraform`.
- `*.tfstate` — будут игнорироваться все файлы, имя которых заканчивается на `.tfstate`.
- `*.tfstate.*` — будут игнорироваться все файлы, содержащие в имени `.tfstate.` (например, с любыми символами после этой точки).
- `crash.log` — будет игнорироваться файл с точным именем `crash.log`.
- `crash.*.log` — будут игнорироваться файлы, которые начинаются на `crash.`, затем содержат любые символы и заканчиваются на `.log`.
- `*.tfvars` и `*.tfvars.json` — будут игнорироваться все файлы, заканчивающиеся на `.tfvars` или `.tfvars.json`.
- `override.tf`, `override.tf.json`, `.terraformrc`, `terraform.rc`, `.terraform.tfstate.lock.info` — будут игнорироваться файлы с точно указанными именами.
- `*_override.tf` и `*_override.tf.json` — будут игнорироваться все файлы, имя которых заканчивается на `_override.tf` или `_override.tf.json`.

Закомментированные строки, начинающиеся с `#`, системой контроля версий игнорируются и не влияют на правила.
